# YouAreFollowingAScammer
Open-source project to call out scammers on Twitter/X using #YouAreFollowingAScammer hashtag

The first time the hashtag #YouAreFollowingAScammer was ever used on X was on Dec 27, 2024 in https://x.com/1GLENCo/status/1872793623399678059.

Since then I have been calling out scammers whenever I see them on X.  Doing that manually is expensive because it costs me time and energy to manually compose the posts where I call them out, or compose the DMs that I've sent to dozens (or maybe even hundreds) of people about them following scammers.  There is no way any one human would be able to win that battle.  Many of the scammers on X are likely malicious bots.  This project is an attempt to give people a tool that can be used determine the liklihood that an account they are interacting with on X is a scammer or a malicious bot.
